* Device Type
Determination:
   per subsystem:
      * RtMidi(over USB, BLE) [[HOTPLUG]]
         Subsystem tells us: [Manufacturer + Device Name] + Connected Port
         ID: a [UUID] from USB/BLE || otherwise use [Manufacturer + Device Name + Connected Port]
         PORT: Connected Port
         PROTOCOL CLASS: [[Midi]]
      * Din Midi
         User has to choose [Manufacturer + Device Name] on a PORT
         PORT : - a music devices port : device Id + Connected Port
                - builtin serial port identifier
         ID: "port"
         PROTOCOL CLASS: [[Midi]]
      * Evdev(over USB) [[HOTPLUG]] *- maybe only use for controller part -*
         USB tells: [Manufacturer + Device Name] + [UUID] + port |-> create device file
         ID: [UUID]
         PORT: USB port? or device file
         PROTOCOL CLASS: [[Evdev]]
      * Free hanging device with analog IO
         User has to choose [Manufacturer + Device Name] without a PORT
         PORT: none
         ID: [Manufacturer + Device Name] + "user defined id ?"
         PROTOCOL CLASS: [[Analog]]
